# Agent instructions

The maintained entry point is [AGENTS.md](AGENTS.md). Read it for model generation,
knowledge retrieval, visual review and tooling changes.

load `AGENTS.md` automatically do not need to read this file.

Construction guidance remains primary. For targeted part questions, follow the
[part-information policy and methods](docs/agent/guides/part-information.md);
never inspect library `.dat` source directly.
