# Linden Row House, run 3: a lean multi-agent build

Run 3 is the cost-reduction version of run 2 (see `../urban-house-snot/COST-ANALYSIS.md`). It uses the same brief and the same 49-submodel contracts, with five changes:
- **Deterministic structure:** the orchestrator builds the slabs, walls (with their openings and sideways-stud mounts), rings and the roof deck in `lib/storey_core.py`. No agent builds structure.
- **Small, fresh worker tasks:** 16 tasks, each a fresh headless Haiku 5.5 agent with a ~2 k-token brief (`briefs/T*.md`, generated by `make_skeletons.py`).
- **Quiet checks:** `check.py` prints at most 12 lines. It adds automatic checks for exposed side studs and for glass with an opaque part right behind it (`contract_check.py`).
- **Scripted orchestration:** `orchestrate.py` dispatches the tasks, runs integration, makes one Opus review call, runs one repair round and the final review. Every call's cost is logged to `costs.jsonl`.
- **Solo-Opus estimate:** `cost_model.py` estimates what a single Opus agent would cost for the same work, from the measured tokens.

## Status
- Infrastructure is built and verified:
  - **Preflight:** the core structure passes 10/10 contract checks.
  - **Exposed-stud check:** it flags exactly the bare mount studs (52 on the ground floor, 28 on floor 2, 32 on floor 3).
  - **Glass check:** it flags the glass-in-front-of-a-wall test fixture, and no correctly framed windows.
  - **`check.py`:** smoke-tested.
  - **Headless calls:** the probe worked, at a baseline context of about 7 k tokens for each worker.

## Launch (from the repo root)
```sh
.venv/bin/python output/urban-house-run3/make_skeletons.py     # regenerate contracts, briefs and module generators (already done)
.venv/bin/python output/urban-house-run3/orchestrate.py --concurrency 4
.venv/bin/python output/urban-house-run3/cost_model.py --overhead <orchestrator-session USD>
```

To check one task by hand:
```sh
.venv/bin/python output/urban-house-run3/check.py <module> <submodel>[,...] [--snap]
```

The outputs are:
- `timeline.jsonl`: phase timestamps;
- `costs.jsonl`: one line per agent call, with `total_cost_usd`, turns, maximum prompt size and per-request usage;
- `integration/r1`, `integration/r2`: contract and floating checks, plus renders at 768 px;
- `integration/r1/tickets.json`: the Opus review tickets;
- `review/`: the final review;
- `COST.json`: the multi-agent total and the two solo-Opus estimates.
