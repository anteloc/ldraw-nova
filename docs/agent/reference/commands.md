# Commands

Generated by `scripts/cli_reference.py` from the argument parser; do not edit. Run `./ldraw-agent COMMAND --help`
for the same text. [cli.md](cli.md) explains contracts, artifacts and exit codes.

Global options go before the command: `--library`: LDraw parts library root (default LDRAW_DIR, then LDRAWDIR, then data/ldraw); `--shadow`: LDCad directory/zip/csl; repeatable, replaces LDRAW_SHADOW or ./data/offLibShadow; `--no-shadow`: Disable external shadow metadata.

#### `flex check`

Diagnose constraints and optionally their actual synthesized asset

- `FILE`
- `--asset`: Generated MPD with its matching flex manifest
- `--block`: Measure one SYNTH block (1-based); source checks still cover all
- `--min-radius`: Explicit geometric bend limit, LDU; not a material certification
- `--max-turn`: Maximum adjacent segment turn, degrees (useful for ribbed hose)
- `--tube-radius`: Measured round cross-section radius for clearance checks
- `--min-separation`: Minimum centreline separation between routes, LDU
- `--length`: Target segment-origin polyline length for a single hose, LDU
- `--length-tolerance` (default 1)
- `--obstacles`: Rigid MPD/LDR in the constraints coordinate frame; conservative box checks
- `--obstacle-section`: Review this obstacle submodel in its local frame
- `--report`: Save the JSON diagnostic report

### `review`

Build if needed, check geometry, render and compare BOMs in one folder

- `FILE`: JSON plan or existing MPD/LDR assembly
- `--outdir`: Dedicated artifact directory (default: SOURCE-review beside input)
- `--force`: Recompute even when the source and options are unchanged (a generated bundle is replaced either way)
- `--no-render`: Run Python checks and BOM only; rendering/comparison stay explicitly skipped
- `--draft`: Also render a model that fails its checks, to see what is wrong
- `--views VIEWS` (default ['home', 'top', 'front'])
- `--timeout` (default 90)
- `--section`: Inspect only this FILE block and its dependency closure; indices become section-local
- `--colour`: Explicit inherited colour for a selected subassembly
- `--detail {summary,full}` (default summary)
- `--contacts {auto,all,none}` (default auto): auto computes contacts for at most 500 physical placements; scope larger models to sections
- `--limit` (default 200): Maximum instance/contact/pair/component rows (does not limit checks)
- `--offset`: First physical occurrence to display
- `--max-instances` (default 100000): Physical expansion budget
- `--full`: Print the complete report instead of the summary (--report always saves it)
- `--quiet`: Print one line: verdict, counts and the first error
