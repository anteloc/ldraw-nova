# Compact front fascia mounting core

**Lesson.** Separate the fascia's sideways stud field from the structural support and decorative skin.

**Construction.** Three source stages build a six-piece core from a plate, a 2 x 2 brick, two 32000 Technic bricks and two 99207 brackets.

**Interfaces.** The bracket faces accept perpendicular panels while the Technic holes provide a different interface family. Inspect each actual mate; the presence of holes does not establish a functioning axle connection.

**Parent context.** This is an unreferenced saved callout corresponding to the front bumper area at main source step 57. The main car's part orientations differ, so treat it as a construction study rather than an exact replacement module.

**Reuse notes.** A useful small starting point for a bumper, dashboard or grille support. Build the intended visible surface separately, align its sockets and check the combined model before repeating the core.
