# Studless Technic propeller plane built as one airframe section

A studless Technic propeller plane kept as one section: a red liftarm fuselage and wings with white panel skins, a 15-long beam as the two-blade propeller on a worm-and-knob gear train, tricycle gear on 42610 wheels plus a tail wheel, and two LSynth flexible axles arcing wingtip to wingtip as the wing leading edges. Measured: span 54 studs, length 60, height 16, 583 placements, 66% Technic. Use it for the layout of a studless Technic trainer: length 1.1× span, low wing, tricycle gear, propeller on a geared nose axle. Inspiration only: the 163 LSynth segments use mirrored matrices, so rebuild the flex leading edges with the flex workflow.

Read [GUIDE.md](GUIDE.md) for the construction, what the parent supplies, how to read the board and the limits; [index.html](index.html) holds the completed-model views. Source: `9394-1_Propeller-Plane.mpd` / `9394 - 9394-2.ldr` (placed by `9394 - Main.ldr`). Style: studless Technic. Atlas: [examples/aircraft-atlas](../aircraft-atlas/README.md).
