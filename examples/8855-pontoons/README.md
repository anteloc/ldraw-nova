# Twin floats on an axle-and-steering-arm truss, with wheels inside the floats

Twin floats for a studded Technic floatplane: each float is a pair of 1×16 Technic bricks with stepped 2×3 plates and an inverted-slope bow, carrying a wheel inside so the plane also rolls; the floats hang on a truss of 3-long axles joined by steering arms and toggle joints that set the strut angles. Rebuild the technique: Technic-brick floats give a long slim hull with pin holes for the truss; steering arms and toggle joints let axle struts meet at non-grid angles. One joint child keeps a skewed part from the original strained model, so this is inspiration only.

Read [GUIDE.md](GUIDE.md) for the construction, what the parent supplies, how to read the board and the limits; [index.html](index.html) holds the build pages. Source: `8855-1.mpd` / `8855 - Pontoons.ldr` (placed by `8855 - Prop Plane.ldr`). Style: studded Technic (1988). Atlas: [examples/aircraft-atlas](../aircraft-atlas/README.md).
